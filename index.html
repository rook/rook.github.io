You describe the cluster. Rook builds and runs it.

Describe the cluster you want: which disks to use, how to protect your data (copies or erasure coding) and where to place it, and which pools and S3 object stores to create. Apply it, and Rook provisions the rest.

  • Upgrade Ceph by changing one line. Rook rolls it out daemon by daemon and checks cluster health as it goes.
  • Drain a node for an OS or Kubernetes upgrade. Rook takes its disks offline only when that is safe for your data.
  • New disks go to work as they appear. To replace a failed disk, mark it and swap it.
  • App teams request S3 buckets and credentials in YAML.

Why Rook

{% include themed-img.html class="why4__icon" src="/images/features/automate.svg" dark="/images/dark/features/automate.svg" alt="" loading="lazy" %}

Cost efficiency

  • 2× less raw space than three copies, same redundancy, with erasure coding
  • NVMe for metadata, HDDs for data: flash-speed metadata at HDD cost
Erasure coding{% include icon.html name="arrow" %}
{% include themed-img.html class="why4__icon" src="/images/features/elasticstorage.svg" dark="/images/dark/features/elasticstorage.svg" alt="" loading="lazy" %}

Runs everywhere Kubernetes runs

On bare metal or in any cloud, on local disks or your provider's block volumes.

Cluster types{% include icon.html name="arrow" %}
{% include themed-img.html class="why4__icon" src="/images/features/opensource.svg" dark="/images/dark/features/opensource.svg" alt="" loading="lazy" %}

Open source, no vendor lock-in

Rook (Apache 2.0) and Ceph (LGPL) run on hardware you choose, and no single company controls the project.

Governance{% include icon.html name="arrow" %}
{% include themed-img.html class="why4__icon" src="/images/features/provision.svg" dark="/images/dark/features/provision.svg" alt="" loading="lazy" %}

Hardware fails, your data stays

Ceph keeps each copy on a different host, rack or zone, rebuilds lost copies on its own, and spreads data onto new disks as you add them.

Failure domains{% include icon.html name="arrow" %}
